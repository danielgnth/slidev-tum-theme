# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub security advisories](https://github.com/danielgnth/slidev-tum-theme/security/advisories/new). Do not open a public issue.

You can expect a first answer within a week. Fixes are released as a patch version of the latest release.

## Supported versions

Only the latest release of `slidev-theme-tum` receives fixes.

## Verifying releases

Every release is published from GitHub Actions with npm trusted publishing and carries npm provenance, SLSA build provenance (Build L3) and SLSA source provenance. See [Releasing](https://danielgnth.github.io/slidev-tum-theme/development/releasing/#verifying-a-release).
