# slidev-theme-tum

[Slidev](https://sli.dev) theme in the corporate design of the Technical University of Munich (16:9), with the layouts and helpers of the `tumbeamer` LaTeX class.

```bash
npm i -D slidev-theme-tum
```

```yaml
---
theme: tum
title: Something with Networking
author: Max Mustermann
themeConfig:
  lang: en # en | de
  chair: Chair of Network Architectures and Services
---
```

**Documentation:** https://danielgnth.github.io/slidev-tum-theme/

**For AI agents:** a complete reference of layouts, options and components is included at `skills/slidev-tum/SKILL.md`.

Releases are published from GitHub Actions with npm provenance and SLSA build and source provenance.
